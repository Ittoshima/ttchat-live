# 🚀 TTChat Pro - ระบบอ่านแชท TikTok Live แบบ Real-time บนเว็บไซต์

เว็บแอปพลิเคชันระดับพรีเมียมสำหรับอ่านคอมเมนต์ TikTok Live แบบเรียลไทม์ พร้อมระบบแจ้งเตือนของขวัญ, ตารางอันดับ Top Gifters, ระบบอ่านออกเสียงคอมเมนต์ภาษาไทย/อังกฤษ (TTS), และหน้าต่าง OBS Studio Overlay พื้นหลังโปร่งใสสำหรับสตรีมเมอร์

---

## ✨ ฟีเจอร์เด่น (Key Features)

- 💬 **Live Chat Feed**: ดึงคอมเมนต์สดแบบ Real-time พร้อมรูปโปรไฟล์, Nickname, `@username`, และ Badge พิเศษ (MOD, Subscriber, Top Gifter)
- 🎁 **Gift & Diamonds Alerts**: แอนิเมชันป๊อปอัปแจ้งเตือนของขวัญพร้อมระบบนับ Combo และคำนวณยอดเพชรรวม (Diamonds)
- 🏆 **Top Gifters Leaderboard**: จัดอันดับผู้ส่งของขวัญสูงสุดแบบเรียลไทม์
- 🔊 **Text-to-Speech (TTS)**: ระบบอ่านออกเสียงคอมเมนต์ภาษาไทยและอังกฤษ ปรับความเร็ว (Speed), โทนเสียง (Pitch), ระดับเสียง (Volume) และสวิตช์เปิด/ปิดได้ทันที
- 🎥 **OBS Studio Browser Source Overlay**: มีหน้าต่าง URL พิเศษ (`/overlay.html?username=...`) พื้นหลังโปร่งใส สามารถนำไปวางบนโปรแกรม OBS Studio ได้ทันที
- 🧪 **Live Simulator Mode**: โหมดจำลองส่งข้อความ, ส่งของขวัญกุหลาบ/กาแล็กซี่, กดไลก์ เพื่อทดสอบระบบได้ตลอดเวลาโดยไม่ต้องรอไลฟ์จริง
- 📥 **Export Chat**: ดาวน์โหลดประวัติข้อความแชทเป็นไฟล์ JSON

## 🚀 วิธีการใช้งาน

### 1. วิธีเริ่มรันระบบ
- **วิธีที่ 1 (ง่ายสุด)**: ดับเบิลคลิกไฟล์ `start.bat` ในโฟลเดอร์ ระบบจะเปิดเซิร์ฟเวอร์และเปิดหน้าเว็บ `http://localhost:3000` ให้อัตโนมัติ
- **วิธีที่ 2 (ผ่าน Terminal)**:
  ```bash
  npm start
  ```
  จากนั้นเปิดเบราว์เซอร์ไปที่ `http://localhost:3000`

### 2. วิธีเชื่อมต่อกับ TikTok Live
1. กรอกชื่อบัญชี TikTok ในช่องค้นหาด้านบน (เช่น `username` หรือ `@username`) ของช่องที่กำลังทำการ Live อยู่
2. กดปุ่ม **"เชื่อมต่อ Live"** (Connect Live)
3. ระบบจะเริ่มดึงข้อความแชท, ยอดคนดู, ยอดไลก์ และของขวัญแบบเรียลไทม์

### 3. วิธีนำไปขึ้นจอ OBS Studio (สำหรับสตรีมเมอร์)
1. ในหน้าเว็บ กดปุ่ม **"OBS Overlay"** ด้านบนขวา
2. กดปุ่ม **"คัดลอก"** ลิงก์ URL (เช่น `http://localhost:3000/overlay.html?username=ชื่อช่องของคุณ`)
3. ในโปรแกรม **OBS Studio**:
   - กดปุ่ม `+` ใน Sources -> เลือก **Browser**
   - นำ URL ที่คัดลอกมาวางในช่อง **URL**
   - ตั้งค่า Width: `500`, Height: `750`
   - กด **OK**
